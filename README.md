# mod_ohmslaw

A small Moodle activity for calculating Ohm's law and electric power from any two positive quantities among voltage (V),
current (I), resistance (R), and power (P).

The activity:

- calculates the two missing quantities immediately in the browser;
- shows the numeric steps used;
- shows all equivalent V/I/R/P relationships with the solved values;
- shows conductance and common unit conversions;
- stores no student-entered calculator values.

## Installation

Copy the `ohmslaw` directory to `mod/ohmslaw` and visit Site administration > Notifications.
